# UI Spec

## Objetivo

Describe que experiencia de interfaz se quiere lograr.

## Problema de UX actual

- que confunde
- que bloquea
- que se siente torpe o ambiguo

## Usuario objetivo

- quien usa esta pantalla
- en que contexto la usa
- que necesita resolver rapido

## Estructura propuesta

- pantalla 1
- pantalla 2
- estados clave

## Comportamientos clave

- accion primaria
- accion secundaria
- estados vacios
- errores
- responsive

## Tono y contenido

- como debe sonar
- que mensajes evitar

## Riesgos

- romper flujo actual
- aumentar complejidad
- inconsistencias con otras vistas

## Criterios de aceptacion

- criterio 1
- criterio 2
- criterio 3

## Validacion

- desktop
- tablet
- movil
- caso feliz
- caso borde
